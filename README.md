# CS340-Client-Server-Development
SNHU CS 340 portfolio featuring a MongoDB animal shelter database and an interactive Python Dash dashboard developed for Grazioso Salvare.
## CS 340 Module Eight Journal Reflection

### How do you write programs that are maintainable, readable, and adaptable?

I try to keep my code organized and easy to understand by separating different tasks into functions and using clear names. In Project One, I created a CRUD Python module to handle database operations. I was able to reuse that same module in Project Two without rewriting the database connection code. This made building the dashboard easier and allowed me to focus on the interactive features. In the future, I could use a similar module for other applications that need to create, read, update, or delete database records.

### How do you approach a problem as a computer scientist?

I start by understanding what the client needs and breaking the requirements into smaller tasks. For Grazioso Salvare, I first worked on connecting to the database, then displaying the records, and finally adding the filters, charts, and map. This project was different from some of my earlier assignments because I had to connect several components to create one working application. I also had to test each feature and troubleshoot problems along the way. In future projects, I would continue using this step-by-step approach and test my queries to make sure the results meet the client's requirements.

### What do computer scientists do, and why does it matter?

Computer scientists use technology to solve problems, organize information, and develop systems that make tasks easier. This project showed me how a database and dashboard can work together to turn large amounts of information into something useful. For Grazioso Salvare, the dashboard makes it easier to identify animals that meet specific rescue training requirements. Instead of manually searching through thousands of records, users can filter the information and view the results through charts and a map. This saves time and helps the organization make better decisions.
